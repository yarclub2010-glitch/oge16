# Тренажёр задания 16 ОГЭ

Веб-тренажёр задания 16 ОГЭ по информатике: программа, которая обрабатывает
последовательность чисел. Программы пишутся на Python, который работает прямо
в браузере (Pyodide). Установка не нужна.

**Открыть:** https://yarclub2010-glitch.github.io/oge16/

Тренажёр задания 15 (исполнитель Робот): https://yarclub2010-glitch.github.io/oge15/

## Возможности

- **Библиотека заданий:** 12 заданий от разминки до трудных: количество, сумма, минимум,
  максимум, среднее, «или NO», сравнение с предыдущим числом, сумма цифр.
  Оба формата ввода ОГЭ: «сначала количество чисел» и «числа до 0».
- **Автоматическая проверка:** программа запускается на наборе тестов — пример из условия,
  особые случаи, случайные данные, тест с максимальным количеством чисел — и получает
  0, 1 или 2 балла по критериям ОГЭ.
- **Свои входные данные:** справа можно ввести любые числа и сразу увидеть верный ответ.
- Понятные сообщения об ошибках Python, подсказка и решение к каждому заданию,
  тёмная тема, телефон и планшет. Программы сохраняются в браузере.

Ссылку на конкретное задание можно отправить ученикам, например
https://yarclub2010-glitch.github.io/oge16/#min-3

## Структура проекта

```
index.html            — страница тренажёра
src/
  main.js             — связывает всё вместе: запуск, проверка, интерфейс
  tasks.js            — задания: условия, эталонные ответы, генераторы тестов, решения
  checker.js          — сравнение ответов, баллы, объяснение ошибок
  editor.js           — редактор кода на Python
  python/runner.js    — запуск программ, ограничение времени, остановка
  python/worker.js    — Python (Pyodide) в отдельном потоке
  style.css           — оформление
tests/                — автотесты (открыть tests/index.html через локальный сервер)
```

## Как добавить задание

В `src/tasks.js` добавьте объект `task({...})` в массив `TASKS`: `id`, `level` (1–4), `title`,
`format` (`'zero'` — числа до 0, `'count'` — сначала количество), `goal` и `output` (текст условия),
функцию `answer(nums)` с верным ответом, `example`, особые случаи `special`, `hint` и эталонное
решение `solution`. Если в условии есть гарантия («всегда имеется число…»), добавьте `guarantee`
и проверку `valid(nums)`. Автотесты сами проверят, что решение получает 2 балла.

## Запуск на компьютере для разработки

Дважды щёлкните `start-server.bat` (нужен Python) — откроется http://localhost:8000.
Отправить изменения на GitHub — `sync.bat`.
