    Что такое задание 16
    
      
    Нужно написать программу, которая читает последовательность натуральных чисел и находит что-то одно: количество, сумму, минимум, максимум или среднее чисел с заданным свойством. На экзамене можно писать на любом языке; здесь — на Python.
    

      
    Два вида входных данных
    

    # Сначала количество чисел, затем сами числа
n = int(input())
for i in range(n):
    x = int(input())
    # обработка x

# Числа до 0 (0 — признак конца, не входит в последовательность)
x = int(input())
while x != 0:
    # обработка x
    x = int(input())   # не забудьте, иначе цикл бесконечный
    

      
    Типовые проверки
    
      
    
        
    x % 3 == 0x кратно 3
    
        
    x % 10 == 4x оканчивается на 4
    
        
    x % 2 == 0x чётное
    
        
    x % 7 != 0x не кратно 7
    
        
    x // 10 % 10вторая цифра с конца (десятки)
    
        
    10 <= x <= 99x двузначное
    
      
    

      
    Минимум и максимум
    
      
    Для максимума начните с 0 — все числа натуральные. Для минимума начните с числа, большего любого допустимого, например 30001, если числа не превышают 30 000. Частая ошибка — взять 1000 или 10000.
    

      
    Клавиши
    
      
    
        
    F9 или Ctrl+Enterвыполнить программу на входных данных справа
    
        
    Escостановить
    
        
    Tab / Shift+Tabотступ / убрать отступ (4 пробела)
    
        
    Enter после строки с двоеточиемредактор сам сделает отступ
    
      
    

      
    Как проверяется решение
    
      
    Тренажёр запускает программу на наборе тестов: пример из условия, особые случаи (нет подходящих чисел, одно число, подходящее число первое или последнее, самые большие числа), случайные данные и тест с максимальным количеством чисел. Числа сравниваются как числа, поэтому 5 и 5.0 — одно и то же. Баллы — по критериям ОГЭ (максимум за задание 16 — 2 балла):
    
      
      
        
    • 2 балла — программа правильно работает на всех тестах;
      • 
        
    • 1 балл — программа выдаёт неверный ответ на одном из тестов;
      • 
        
    • 0 баллов — неверные ответы на двух и более тестах.
      • 
      
    
      
    Python работает прямо в браузере (Pyodide). При первом открытии он загружается из интернета — это может занять несколько секунд. Тренажёр не заменяет проверку экспертами на экзамене, но устроен по тем же правилам.
